## 👀 About the Project

**Local Sole** is a shoe-shopping website designed to make browsing footwear collections simple, stylish and user-friendly.

The project focuses on a clean shopping interface, responsive layouts and interactive front-end experiences using core web technologies.

## 🚀 Features

- 👟 **Footwear Collections** — Browse available shoes and product listings.
- 🛍️ **Shopping Experience** — Dedicated shopping and product pages.
- 🛒 **Cart & Checkout Pages** — Pages for reviewing items and proceeding through checkout.
- ❤️ **Wishlist** — A dedicated page for favourite products.
- ⚖️ **Product Comparison** — A page for comparing footwear options.
- 👤 **Account Page** — A dedicated account interface.
- 📦 **Order Pages** — Order confirmation and order-related interfaces.
- 📱 **Responsive UI** — Designed to work across different screen sizes.
- 🎨 **Modern Design** — Clean layouts, styling and interactive visual elements.

*Note: Feature descriptions refer to the available website pages. Actual functionality may depend on the implementation of each page.*

## 💻 Run Locally

No framework installation is required for the basic static website.

1. Clone the repository:

   ```bash
   git clone https://github.com/ritikofficial787-cpu/Local-Sole.git
   ```

2. Open the project folder:

   ```bash
   cd Local-Sole
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.
